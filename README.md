# QuickSketch Multiplayer

A multiplayer drawing and guessing game inspired by Skribbl.

## Features

- Create rooms
- Join existing rooms
- Multiplayer synchronization
- Drawing canvas
- Shared room state

## Tech Stack

Frontend
- React
- JavaScript
- React Router
- CSS

Backend
- Node.js
- Express.js

## What I Learned

- Client-server communication
- REST APIs
- Multiplayer state synchronization
- React component architecture
